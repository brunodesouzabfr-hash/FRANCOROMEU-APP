# Franco Romeu — pacote de publicação visual v2

Este pacote contém o `index.html` integrado com a identidade vetorial oficial,
favicons completos e uma biblioteca local de imagens contextuais para Home,
Sobre, Ambientes, Projetos 3D e Portfólio.

## Publicação

Envie **todo o conteúdo desta pasta** para a raiz pública do site, mantendo a
estrutura `assets/`. O HTML usa caminhos relativos e não depende de Unsplash ou
i.ibb para imagens da interface.

## Política visual

- Logomarca, logomark, lockups, selo e favicon usam SVGs oficiais.
- Imagens conceituais permanecem identificadas como referência visual quando o
  próprio componente já possuía esse aviso.
- Os visuais gerados não devem ser descritos como obras executadas pela Franco
  Romeu sem comprovação documental.
- Imagens personalizadas salvas pelo usuário são preservadas; somente URLs
  antigas de Unsplash/i.ibb são migradas para a biblioteca local.

## Estrutura

- `assets/brand/`: SVGs usados e biblioteca completa de mestres vetoriais.
- `assets/icons/`: favicons e ícones para navegador/PWA.
- `assets/media/`: imagens locais organizadas por seção, estilo e projeto.
- `assets/social/`: imagem Open Graph e logomark para dados estruturados.
