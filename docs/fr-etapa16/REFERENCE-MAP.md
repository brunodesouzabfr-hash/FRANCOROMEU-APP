## Síntese FR original

### Portfólio — universo 1

`Arquivo gravitacional`: o conteúdo horizontal existe no DOM; ao fundo, um campo de quadros/partículas em espiral responde ao progresso. A direção de arte usa carbono, petróleo, ouro, cobre e bordô. A hierarquia é Stardos + Rokkitt + Share Tech Mono.

### Portfólio — universo 2

`Frequência de obra`: o arquivo social aparece no meio da página como uma estação separada. Os cards têm estrutura técnica, provider, formato, tema, duração e status. A composição usa grid FR e deslocamento horizontal mais estável, sem repetir a espiral de abertura.

### Projetos 3D

`Cubo de decisão`: o cubo atual continua sendo o objeto principal. Arrastar orienta; scroll/roda opcional avança estados; cada estado atualiza uma face lógica e, depois, um painel lateral. O painel usa grid e não encobre os controles do objeto.

### Ambientes

`Atlas de atmosferas`: o hero canônico conduz a uma lista de 12 linguagens. Uma prévia informa conceito e material. O clique abre um dossiê amplo, com galeria, decisão técnica, cuidados de obra, serviços e ligação à calculadora.

## Regras de propriedade intelectual

- Não copiar HTML, CSS, JS, classes, nomes de componentes, conteúdo editorial ou assets.
- Não usar screenshots das referências na versão pública.
- Não baixar imagens ou vídeos dos sites para compor o portfólio FR.
- Relatórios e screenshots de pesquisa ficam em documentação/local e não são distribuídos como parte do produto.
- Implementar por comportamento e objetivo, com tokens, dados e estrutura próprios.

## Como ler os relatórios do FR Lab

Prioridade:

1. `fr-translation-plan.md`: decisões já traduzidas para a FR;
2. `design-system-reference.md`: evidência observada/inferida;
3. `analysis-brief.md` ou `codex-summary.md`: objetivo específico da captura;
4. `design-system.json`: consulta de detalhe;
5. `evidence.md`: limites e metadados.

`page-desktop.html`, `page-mobile.html`, `animations.json`, `layout-map.json`, CSS e manifests não devem ser despejados no contexto principal. O Codex só deve abrir uma evidência bruta quando uma pergunta concreta não estiver respondida nos relatórios curados.
